# Генерация отчета по практической работе (.docx)

## Когда применять
Используй этот скил, когда пользователь просит создать новый отчет по практической или лабораторной работе в формате `.docx`.

## Алгоритм работы
1. Изучи реальную структуру проекта (модели C#, `DbContext`, миграции SQL Server, компоненты `.razor`, сервисы и `Program.cs`), чтобы описывать только реально существующий код и архитектуру.
2. Создай или обнови `.docx`-файл через Python-скрипт с использованием библиотеки `python-docx`.
3. Если в папке проекта уже есть образец предыдущего отчета (например, `ОТЧЕТ ПО ПРАКТИЧЕСКОЙ РАБОТЕ № 15 CineNote Мурашко.docx`), скопируй его как шаблон, чтобы сохранить титульный лист, колонтитулы и стили оформления, заменив только внутреннее содержание.

## Обязательная структура отчета
- **Титульный лист** (номер и тема работы, дисциплина, ФИО студента, группа, год).
- **Цель работы** и **Постановка задачи**.
- **Ход работы** (пошаговое описание реализации с привязкой к конкретным файлам проекта `.razor`, `.cs`, таблицам SQL Server).
- **Фрагменты программного кода** (ключевые методы, запросы EF Core или разметка компонентов — оформлять моноширинным шрифтом без лишних комментариев).
- **Вывод** (итоги выполнения задач и полученные навыки).

## Требования к оформлению и тексту
- Шрифт основного текста: Times New Roman, 14 пт, межстрочный интервал 1.5, выравнивание по ширине, абзацный отступ 1.25 см.
- Шрифт для блоков кода: Courier New или Consolas, 10–11 пт, одинарный интервал.
- Стиль изложения: строгий технический/академический на русском языке, в безличной форме («Разработан компонент...», «Настроена связь в БД...», «Реализована валидация...»).
